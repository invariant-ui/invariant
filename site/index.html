Invariant compiles your React, Vue and Angular components, Storybook and design tokens into one machine-readable contract. Agents get real context, not hallucinated props.

Compile

Extract the facts. Don't guess them.

Source adapters read your code statically and normalize everything into a shared intermediate representation. A pure compiler turns that into the contract. Nothing from your project is executed.

SourcesReact · Vue · Angular
Storybook · tokens
→
Invariantdiscover · extract
reconcile · verify
→
ContractJSON + evidence
+ report

Deterministic

Props, events, defaults and token values come from static analysis. Recompiling unchanged sources gives identical bytes.

Evidence for every fact

Each fact links back to the file and line it came from, so you can always ask "why does the contract say this?"

Framework-neutral

The contract doesn't depend on a frontend framework or on MCP. Framework quirks live in extension metadata.

discovered documented inferred approved

Every fact carries a status. Guesses are never passed off as discovered, and conflicting sources are reported, not hidden.

Verify

Know when the contract is stale or tampered with.

Verify checks the compiled output on its own. With --fresh it also recompiles, and if your sources have moved on it tells you which components, tokens and sources changed. Put it in CI.

$ invariant verify
✓ contract structure✓ cross-references✓ content hash✓ evidence ids✓ manifest file hashes
$ invariant verify --fresh
✗ verify.stale: sources changedcomponents: +0 -0 ~1~ component:button (description)
$ invariant validate src/
! Button.tsx:14 color rgb(104 86 224)
  not the value of any token
! Card.tsx:6 padding: 13px
  not the value of any spacing token
✗ Card.tsx:9 unknown prop "tone"
  basis: discovered

Validate checks component props and literal colors (hex, rgb, hsl, named), spacing and typography against your tokens. Only literal values are checked, and every finding says on what basis: discovered, documented, inferred or heuristic.

Review

Humans decide. Machines never self-approve.

Conflicts and inferred facts land in a review queue. Your decisions are saved in a committed file and applied on every compile.

Conflicts surfaced

When Storybook and code disagree, both values stay in the contract with their evidence. Nothing is silently dropped.

Inferred stays inferred

Rules the engine infers are never promoted to approved policy automatically. You approve, reject or dismiss each one.

Decisions in git

Approvals live in invariant.decisions.json and are bound to a fingerprint of the fact, so they expire when the evidence changes.

Connect

One command to wire up your agent.

Invariant serves the compiled contract over a read-only MCP server. Agents look up components, tokens and usage, and check their own code before they hand it back.

$ invariant agent init claude-code   # also: cursor, codex, windsurf, all

10 read-only tools

get_component, get_design_tokens, search_design_system, validate_component_usage and more.

Always current

The server reloads when you recompile. A missing or tampered contract is never partly served.

Treats your text as untrusted

Results are marked untrusted and returned as structured JSON. Generated agent config never includes free-form descriptions.

Get started

Run it on your own project.

Needs Node 24+ and pnpm. Invariant isn't on npm yet, so build it from source and link it.

Build Invariant

git clone https://github.com/mcarlucci/invariant.git
cd invariant
pnpm install && pnpm build
cd apps/cli && pnpm link --global

Compile your design system

cd /path/to/your-project
invariant init
invariant compile
invariant compile --watch   # optional: recompile on every change

Explore and connect

invariant components list
invariant components inspect Button --evidence
invariant agent init claude-code
